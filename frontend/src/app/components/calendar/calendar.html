settings Google Calendar Setup
  1. Go to console.cloud.google.com and create a project
  2. Enable the Google Calendar API
  3. Go to APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web application)
  4. Add http://localhost:5000/api/google-calendar/callback as an Authorized redirect URI
  5. Copy your Client ID and Client Secret
  6. Open D:\Growty\beckend\appsettings.json and fill in: 
    "Google": {
  "ClientId":     "your-client-id.apps.googleusercontent.com",
  "ClientSecret": "your-client-secret"
}
  7. Restart the backend, then click Connect to Google Calendar again
